## APIs

No public developer API portal has been identified for Cencora. Integration is delivered through an Axway-based central EDI platform (over 800,000 EDI messages per day with 23,000+ trading partners) and a Cell and Gene Therapy (CGT) Integration Hub for real-time biopharma and provider data exchange. Contributions welcome if public APIs are identified.
